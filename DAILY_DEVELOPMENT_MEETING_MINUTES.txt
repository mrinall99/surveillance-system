     * Part 3: Modern React Dashboard to show the video feed and live alerts.

   - Node.js Backend:

       directly in the web app without editing config.yaml files manually.
   - React Frontend:
     * Built a sleek, cyberpunk dark-mode command center.
     * Added live video feed player, latency trackers, and DEFCON security status.
     * Built the first-time setup wizard and secure login screen.

3. Challenges Overcome:

SESSION 2: SPATIAL INTELLIGENCE & POLYGONAL ZONES (PHASE 2)
--------------------------------------------------------------------------------

1. What We Planned:
   - Teach the system spatial awareness: recognize WHERE an object is standing.
   - Allow the user to draw custom virtual fences/boundaries directly on the video.
   - Classify danger into 4 clear levels (CRITICAL, HIGH, MEDIUM, LOW).

2. What We Built & Delivered:
   - Geometry Engine (Ray-Casting Algorithm):
     * Implemented point-in-polygon math in simple JavaScript.
     * The system calculates the bottom-center of any person or vehicle and
       checks if that dot falls inside any drawn zone.
   - 4-Level Threat Intelligence Engine:
     * Level 1 (CRITICAL): A person or vehicle steps inside a Restricted Zone.
     * Level 2 (HIGH): A person loiters in a Monitored Zone for more than 30 seconds.
     * Level 3 (MEDIUM): Normal activity inside a Monitored Zone.
     * Level 4 (LOW): Harmless background movement (animals, trees, safe zones).
   - Visual Zone Editor:
     * Added a point-and-click drawing tool on the "Cameras" page.
     * Users can click directly on the live camera stream to drop pins and create
       any shape (e.g., restricted door, parking area).
   - Full Documentation:
     * Created dedicated technical manuals and simple layman explanation guides
       for both Phase 1 and Phase 2 in the docs/ folder.

SESSION 3: POLISH, BUG FIXING & CUSTOM "JALDI" AUDIO ALARM
--------------------------------------------------------------------------------

1. What We Addressed:
   - User reported: "There is no colored polygon boundaries in my live feed."
   - User reported: "The server is not starting (EADDRINUSE 5000)."
   - User requested: "Instead of just pulsing color, add beep sound effect."
   - User requested: "Use the jaldi.mp3 from audio folder instead of the beep sound."
   - User reported: "It is not playing audio when entered restricted zone."

2. Root Causes Identified:
   - Zone Display Issue: An earlier background server process held an empty zone
     array in memory and overwrote surveillance.json during login.
   - Port 5000 Busy: A background instance of the backend was already running.
   - Audio Not Playing on Breach: The user was testing while on the Cameras page
     (/cameras - ZoneEditor), but the audio alert was only wired to Dashboard.
     Also, web browsers block automatic audio until the user clicks the page once.

3. Fixes & Enhancements Delivered:
   - Database Self-Healing:
     * Added auto-seeding in database.js so default zones (Restricted Main Zone,
       Monitored Perimeter) can never be accidentally erased.
   - Vivid Boundary Overlays:
     * Increased polygon stroke lines, added neon glows, anchor corner dots,
       and labels that do not get cut off at screen edges.
     * Added a "ZONES: ON / OFF" button on the video player toolbar.
   - Port Freeing:
     * Cleanly stopped background tasks so port 5000 is 100% free for user terminal.
   - Custom Voice Alarm ("jaldi.mp3"):
     * Copied audio/jaldi.mp3 to client/public/audio/jaldi.mp3.
     * Built a Web Audio API audio player in audioAlert.js that pre-decodes the MP3
       directly into browser memory for instant, glitch-free playback.
     * Added automatic window click listeners to unlock browser audio restrictions.
     * Added breach detection and jaldi.mp3 playback to BOTH the Dashboard and
       the Cameras (Zone Editor) page.
     * Added instant "TEST JALDI AUDIO" buttons on both pages for one-click testing.
