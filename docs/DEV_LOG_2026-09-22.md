## ✅ Task 2 — Authentication System Replacement

### Goal
Remove the existing username/password authentication system entirely and replace it with a **Single-Owner Master Secret Key** system — no external parties can log in, only the owner.

### Discussion
The original auth used a `username` + `password` model with bcrypt hashing. For a private, owner-operated surveillance system, this was unnecessary complexity. The new design treats the system as a **single-owner gateway** — one secret key, one owner.

Key security considerations discussed:
- **Timing attacks** — naive string comparison leaks whether a key is "close" to correct via response time differences. Solution: use Node.js `crypto.timingSafeEqual` which always takes the same time regardless of match.
- **Brute-force protection** — without rate limiting, an attacker could try millions of keys. Solution: implement an in-memory **5-strike lockout** that freezes the auth endpoint for 15 minutes after 5 consecutive failures.
- **Audit trail** — all login events (success, failure, lockout) are written with timestamps to `data/surveillance.json` for forensic review.

```
        ↓

```
